## Reporting a vulnerability

**Do not open a public issue for security vulnerabilities.**

Report privately via [GitHub Security Advisories](../../security/advisories/new) or
email [security contact] with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix, if you have one

- Acknowledgement within [e.g. 48 hours]
- An initial assessment within [e.g. 5 business days]
- Credit in the fix's release notes, if you'd like it (opt-in)
