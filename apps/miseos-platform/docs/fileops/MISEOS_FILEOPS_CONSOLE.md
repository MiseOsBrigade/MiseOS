# MiseOS FileOps Console

The MiseOS FileOps Console is the first repo-manager station for file handling and agentic document workflows.

## Workflow

```txt
Prepare → Cook → Orchestrate → Deploy → Observe
```

## Provider Routing

| Provider | Use |
|---|---|
| xAI Files | Private uploaded files and immediate chat attachments |
| Collections | Durable semantic search and RAG-style document memory |
| Fal | Media workflows and CDN URL handoff |
| Catalyst | Backend service layer, API Gateway, Functions, Datastore, Filestore, Jobs, and Logs |

## Interactive Proof

```txt
apps/fileops-console/index.html
```

The console is static, self-contained, and safe to open locally. It simulates upload records in `localStorage`, builds xAI Responses-style payloads, and demonstrates tool toggles for Web Search, X Search, Code Interpreter, and Collections Search.
