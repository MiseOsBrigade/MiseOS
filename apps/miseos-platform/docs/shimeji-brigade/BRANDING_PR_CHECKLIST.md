# Shimeji Brigade branding PR checklist

- [ ] Tokens and CSS variables agree on names and hex values.
- [ ] Logo mark, wordmark, badge, social card, and palette sheet render on dark and light previews.
- [ ] Copy uses proof-first, kitchen-brigade language without investment/value claims.
- [ ] Character silhouettes remain readable at 32px and 128px.
- [ ] Sprite manifests validate with no binary frames committed.
- [ ] Missing/broken frames select the procedural fallback without crashing.
- [ ] New UI text follows `UI_WRITING_SYSTEM.md`.
- [ ] Reference rights and source notes are recorded before publishing art.
- [ ] No secrets, wallet logic, private keys, or minting code entered the runtime.
- [ ] Required checks and a browser preview are attached to the PR.
