# Shimeji Brigade designer notes

- Draw at canonical 128×128 before deriving animation frames.
- Preserve transparent padding so billboard sprites do not visibly jump.
- Keep face/hat contrast above the panel background.
- Mizu reads as blue-haired, cool teal/blue accents, quick and curious.
- Kurogami reads as chef whites, gold/orange heat accents, calm and protective.
- Use a 4px-ish visual stroke at 128px; scale with nearest-neighbor for pixel assets.
- The procedural fallback must be charming enough to be a deliberate preview, not a broken-image icon.
- Never place private reference attachments or unredacted source files in the runtime pack.
