# MiseOS Three-Layer Ecosystem Viewer

Dependency-free interactive reference implementation for the MiseOS category model.

Open `index.html` directly, or serve it from the repository root:

```bash
python3 -m http.server 8080
# http://localhost:8080/apps/ecosystem-model/
```

The visual defaults to Layer 2 because Agent Utility is the strategic bridge between character identity and ecosystem participation.
