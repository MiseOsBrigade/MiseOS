# Merge & PR — Comparison Notes

| Lens | This station does | This station avoids |
|---|---|---|
| Repo role | Check PR readiness and merge gates. | Merge-first automation. |
| Trigger style | Trusted collaborator command or manual workflow dispatch. | Untrusted fork merge paths. |
| Write behavior | Apply only when explicitly requested. | Silent auto-merge. |
| Learning value | Teaches why gates matter before plating a branch. | Treating all branches as equally safe. |
