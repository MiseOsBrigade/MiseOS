# MiseOS Naming Conventions

## Repository

```txt
miseos-bootstrap-registry
```

## npm packages

```txt
@miseos/cli
@miseos/agent-sdk
@miseos/policy-engine
@miseos/release-sentinel
@miseos/repo-steward
```

## containers

```txt
ghcr.io/mise-os/miseos-runner
ghcr.io/mise-os/miseos-policy-checker
ghcr.io/mise-os/miseos-docs-builder
```

## manifest IDs

```txt
miseos.cli
miseos.agent-sdk
miseos.policy-engine
miseos.release-sentinel
miseos.repo-steward
miseos.runner
```

## Rule

Human-facing names can be beautiful. Machine-facing names must be boring, stable, lowercase, and predictable.
