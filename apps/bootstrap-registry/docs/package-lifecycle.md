# MiseOS Package Lifecycle

## 1. Proposed

A new capability is added with a manifest, owner, artifacts, permissions, trust gates, and agent contract.

## 2. Experimental

The capability can run in dry-run or advisory mode only.

## 3. Active

The capability can be used by MiseOS workflows after validation and review.

## 4. Deprecated

The capability remains visible but should not be used for new workflows.

## 5. Archived

The capability is retained for historical evidence only.

## Update policy

| Change type | Default action |
|---|---|
| Patch | Automated validation allowed |
| Minor | Maintainer review required |
| Major | Human review required |
| Permissions | Human review required |
| Source registry | Human review required |
| Security policy | Human review required |
