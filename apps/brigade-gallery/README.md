# MiseOS Brigade Gallery

React + Vite gallery for the MiseOS player cards: the **Master Roster** (75 cards from the Mise Orchestra Master Roster, with departments and rarity tiers) and the **Brigade Gallery** (68 brigade cards, MO-001..MO-072). Each card has a copy-to-clipboard `mise card run <slug>` command.

```bash
npm install
npm run dev      # local dev server
npm run build    # type-check + production build to dist/
```

`prototype/` holds the earlier standalone HTML holo-card roster and registry atrium gallery.
