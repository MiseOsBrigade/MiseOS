# Contributing

Thank you for improving MiseOS.

## Local validation

```bash
npm test
```

## Commit style

Use Conventional Commits:

```text
feat: add capability
fix: repair behavior
docs: update documentation
security: harden trust boundary
ci: update workflow
```

## Pull request rules

- Keep changes small and explainable.
- Include tests or a validation note.
- Do not commit secrets, private keys, or production credentials.
- Update docs when behavior changes.
