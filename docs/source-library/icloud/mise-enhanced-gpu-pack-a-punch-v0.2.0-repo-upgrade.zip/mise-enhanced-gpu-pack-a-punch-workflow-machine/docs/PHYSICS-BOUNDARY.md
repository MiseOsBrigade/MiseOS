# Physics boundary

This repository intentionally separates metaphor from implementation.

## Metaphor

Words such as measurement, quantum-inspired, coherence, complexity, coordinates, and Pack-a-Punch describe how the workflow system organizes signals and routes work.

## Implementation

The implementation uses:

- GitHub Actions YAML,
- Node.js scripts,
- Python scripts,
- JSON policies,
- Git diff metadata,
- standard CPU runners,
- optional real GPU self-hosted runners.

## Not claimed

This project does not claim:

- unlimited energy access,
- computation beyond Planck units,
- physical zero-point energy extraction,
- cosmic-particle-powered runners,
- faster-than-physics computation.

For repository engineering, the useful translation is: measure first, gate risk, route expensive jobs only when justified, and emit evidence.
