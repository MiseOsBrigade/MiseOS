# 60-Second Demo Video Script — Mise PR

## 0–5 seconds
Show a messy pull request.

Voiceover/text:
“AI agents made code faster. They did not make review attention cheaper.”

## 5–15 seconds
Show the PR files changed tab: source files, config, workflow, tests missing.

Voiceover/text:
“Most review tools jump straight into code comments. Mise PR asks the earlier question: is this PR reviewable yet?”

## 15–35 seconds
Show the Mise PR comment.

Voiceover/text:
“Mise PR creates a review packet with scope, churn, risky paths, missing tests, weak descriptions, issue-link checks, and estimated reviewer attention.”

## 35–48 seconds
Show Markdown and JSON output.

Voiceover/text:
“Humans get one clean summary. AI agents and enterprise workflows get structured JSON.”

## 48–60 seconds
Show GitHub Action install snippet.

Voiceover/text:
“No LLM required. No code leaves your repo. Pull requests prepped before review.”
