# Product Hunt Outreach List — Mise PR

Do not ask for upvotes. Ask people to try it, comment, and share honest feedback.

## Best-fit people to contact

1. Open-source maintainers with active PR queues
2. Engineering managers who adopted AI coding agents
3. DevTools founders and indie hackers
4. GitHub Actions marketplace users
5. Security-conscious teams that avoid LLM code review
6. Senior engineers who review junior or AI-generated PRs
7. Productivity/tooling creators on X, LinkedIn, Threads, and Product Hunt

## DM template

I’m launching Mise PR, a lightweight GitHub Action that turns messy pull requests into clean review packets before humans or AI agents review them.

It’s not an AI code reviewer — it checks whether a PR is actually reviewable first: scope, churn, risky paths, missing tests, weak descriptions, and issue/spec links.

Would appreciate a real comment or critique on launch day, especially from your maintainer/tooling perspective.
