# Review Packet Skill

Use this skill to convert a pull request into a concise review packet.

## Inputs
- PR title
- PR description
- Changed files
- Additions/deletions
- Risk policy

## Output
- Risk level
- Review blockers
- Warnings
- Recommended next moves
- Changed-file map
- Estimated attention budget

## Constraints
- Do not claim code correctness.
- Do not fabricate tests.
- Do not over-comment.
- Always separate deterministic findings from optional AI interpretation.
