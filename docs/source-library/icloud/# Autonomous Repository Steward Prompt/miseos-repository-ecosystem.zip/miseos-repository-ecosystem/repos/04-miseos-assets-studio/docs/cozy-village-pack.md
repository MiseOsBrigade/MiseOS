# Cozy Village Pack

Flagship pack concept for MiseOS Assets Studio.

- 91 assets
- 13 categories
- 10 decoratable prebuilds
- four seasonal moods
- playable demo world
- approximately 60k triangles total
- shared vertex-color material strategy where possible
- baked vertex ambient occlusion
- deterministic builders for repeatable layout generation

Do not claim KTX2 texture support unless textures are actually used and processed.
