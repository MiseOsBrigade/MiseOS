# Character Roster

Characters are workflow operators. Each one maps to a function, gate, or workflow.

- Repo Pet: repository health and healing
- Sear Samurai: quality and pressure checks
- Scale Oni: capacity and growth
- Repo Steward: branch and merge governance
- Release Sentinel: launch protection
- Analytics Engine: insight and intelligence
- Attestation Gate: authorization and policy
- MiseOS CLI: command execution
- Docs Builder: documentation and indexing
- Kurogami: orchestration
