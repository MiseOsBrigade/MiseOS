# AI Types and Capabilities

## Capability levels

- ANI: current narrow AI systems.
- AGI: theoretical general intelligence.
- ASI: hypothetical superintelligence.

## Functional depth

- Reactive machines
- Limited memory
- Theory of mind, experimental
- Self-aware AI, conceptual

## Business paradigms

- Predictive AI
- Generative AI
- Agentic AI
- Multimodal AI
- Causal AI
- Neurosymbolic AI

MiseOS treats current production models as narrow, limited-memory tools. Theoretical categories are documented for taxonomy, not used as claims about current product capability.
