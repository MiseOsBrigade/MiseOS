# Research Brief

This bundle used project-chat source material plus current web research through Agentic Search by Liner and direct web search.

## Verified repository best-practice inputs

- GitHub community health files and default `.github` repositories.
- GitHub Actions secure use: least-privilege permissions, OIDC, secret handling, action pinning.
- OpenSSF Scorecard for automated security-health checks.
- Semantic Versioning 2.0.0 for release semantics.

## Access limits

Statista, CB Insights, Wiley, and PitchBook are not directly connected in this environment. Their paywalled market datasets were not used as direct sources. Market guidance in this bundle is framed as product strategy, not externally validated market sizing.
