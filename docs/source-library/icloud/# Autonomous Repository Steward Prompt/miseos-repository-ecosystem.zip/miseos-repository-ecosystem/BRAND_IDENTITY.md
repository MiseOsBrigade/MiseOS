# MiseOS Brand Identity

**MiseOS** is the operating system for autonomous development.

## Tagline

**Plan. Build. Launch. Grow.**

## Voice

- Builder-first, not guru-first.
- Operational, warm, and precise.
- Clear about uncertainty.
- Playful characters are allowed, but clarity always wins.

## Visual language

- Obsidian black surfaces
- Gold command lines
- Ember action states
- Cream text
- Teal verification accents
- Card/game UI motifs
- Circuit boards, city grids, workbook sheets

## Character system

Each character represents an operational role. They are not decorative mascots only; they map to workflows, checks, and permissions.
