# MiseOS 3D Character Collectible Carousel

> A grouped, GitHub-compatible gallery for the MiseOS 3D character collection.
>
> **Canonical ecosystem:** 112 character collectibles + 23 separate registry products.
> **Current repository-backed roster in `characters.html`:** 75 named demo characters.
> The remaining 37 canonical character identities must be added to the roster source before their cards are generated.

## Asset contract

Each character uses the following canonical paths:

```text
media/images/3d/<character-slug>/hero.webp
media/models/3d/<character-slug>/<character-slug>.glb
cards/<token-id>-<character-slug>.md
metadata/<token-id>-<character-slug>.json
```

GitHub READMEs do not execute custom JavaScript carousels. Each house below therefore uses a wide HTML table, which behaves like a horizontally scrollable collectible strip on narrow screens.

## Canonical roster completion gate

The carousel intentionally stops at the 75 character names currently exposed by `characters.html`. Add the remaining 37 canonical identities to the source roster before generating their artwork, GLB models, metadata, or collectible cards.

Required validation before publishing:

- Every card name is unique.
- Every token ID is unique and stable.
- Every hero image path resolves.
- Every GLB path resolves.
- Every character belongs to exactly one house.
- Registry manifests remain excluded from character counts.
- Placeholder media is never presented as complete or minted.
