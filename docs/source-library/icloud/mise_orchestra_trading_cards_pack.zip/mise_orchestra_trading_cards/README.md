# Mise Orchestra Trading Cards

Creator collectible card pack for **Mise Orchestra: Kitchen Chaos DevOps Universe**.

## Contents

- `cards/png/` - 23 generated trading card PNGs
- `metadata/erc721/` - ERC-721-ready JSON metadata
- `data/mise_orchestra_cards.csv` - full roster and trait table
- `data/mise_orchestra_collection_manifest.json` - collection manifest
- `prompts/image_generation_prompts.md` - reusable image prompts
- `.github/workflows/validate-card-metadata.yml` - metadata validation workflow

## Rules

- Chain target: Polygon
- Token standard: ERC-721
- Royalty interface: ERC-2981
- Framing: creator collectible, lore, access, provenance, and community utility
- Avoid: investment promises, resale promises, price appreciation claims, or guaranteed value language
