A **video-js** artifact (**React + Framer Motion + GSAP + React Three Fiber**) that
choreographs the entire brigade roster into a single cinematic sequence.

- Driven by the canonical roster in [`artifacts/dashboard/src/lib/brigade-data.ts`](../dashboard/src/lib/brigade-data.ts).
- Each brigade enters on its own accent color; the whole thing resolves to gold.
