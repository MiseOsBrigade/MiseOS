**Patron brigade · Engineering & Development** &nbsp;`#5B8DEF`

> _"Plate it three ways before it leaves the kitchen."_ — **UX Chef**, Experience Designer

This is the **test kitchen** — a component preview server where UI is prototyped,
compared, and reviewed before it graduates into the main app. Each component gets
its own isolated URL for side-by-side variant exploration on the canvas.

## What lives here

- A **Vite** preview server that serves isolated component previews under `/preview/`.
- The staging ground for design variants embedded as iframes on the canvas.

## Run this station

```bash
pnpm --filter @workspace/mockup-sandbox run dev
```
