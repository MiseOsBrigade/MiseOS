## 🍳 The premise

Every technical workflow is a kitchen. A repo is a pantry; a pipeline is a service
line; an incident is a grease fire. **MiseOS** is the operating mythology that keeps
the kitchen running — **Mise** (everything in its place) against **Entropy** (chaos).

The kitchen is run by a **brigade**: seven teams of specialists, seventy-five agents
in total, each owning exactly one station. Read the full story in the
**[Manifesto](docs/MANIFESTO.md)**.

## 4 · Motion & 3D

MiseOS is a moving brand. The launch film and the 75-variant orchestra are built
with **React Three Fiber + Framer Motion + GSAP** (see `artifacts/launch-film` and
`artifacts/mise-orchestra`).

- **Easing:** confident, never bouncy. Steam rises; it doesn't spring.
- **Hero motion:** broth swirl + gold filaments + the ladle pour.
- **3D:** depth via subtle parallax and volumetric light, not gratuitous spin.

## 🚀 Quickstart

```bash
# Stock the pantry
pnpm install

# Mise-en-place — typecheck everything
pnpm run typecheck

# Plate up — build every artifact
pnpm run build

# Run a single station (examples)
pnpm --filter @workspace/dashboard run dev
pnpm --filter @workspace/api-server run dev
pnpm --filter @workspace/launch-film run dev
```

## 🍜 Meet the repo mascot

A little chef roams this very repository. Send it wandering:

```bash
pnpm run roam:repo
```

Best-practice use cases:

```bash
# New contributor tour, bounded and readable
pnpm run roam:repo

# Safe first-line previews for small source/docs/config files
pnpm run roam:repo:peek

# Container/environment inspection with a shallow depth limit
pnpm run roam:container
```

It's read-only, secret-aware, and intentionally separate from production runtime code. Details in
**[`tools/repo-shemi-roamer`](tools/repo-shemi-roamer/README.md)** and the
**[use-case guide](tools/repo-shemi-roamer/USE-CASES.md)**.
