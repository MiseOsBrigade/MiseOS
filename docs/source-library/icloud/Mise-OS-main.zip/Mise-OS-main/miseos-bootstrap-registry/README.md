# MiseOS Bootstrap Registry

This directory is generated by the parent repository importer:

```bash
node tools/import-miseos-bootstrap-registry.mjs
```

The importer materializes the full bootstrap registry under this folder:

```txt
registry → runtime → CLI → policy engine → release sentinel → autonomous updates
```

## Primary bootloader

| Layer | Artifact |
| --- | --- |
| Repository | `miseos-bootstrap-registry` |
| Primary package | `@mise-os/cli` |
| Primary container | `ghcr.io/mise-os/miseos-runner` |
| Primary automation | `@mise-os/release-sentinel` |
| Governance layer | `@mise-os/policy-engine` |

## Publish sequence

1. Publish `ghcr.io/mise-os/miseos-runner`
2. Publish `@mise-os/cli`
3. Publish `@mise-os/policy-engine`
4. Publish `@mise-os/release-sentinel`

The import workflow has been added at `.github/workflows/import-miseos-bootstrap-registry.yml`.
