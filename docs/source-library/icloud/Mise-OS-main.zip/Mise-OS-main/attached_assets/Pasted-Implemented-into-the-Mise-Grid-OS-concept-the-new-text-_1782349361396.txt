New operating model

The system now has three brains:

Brain	Purpose
Grid Brain	Organizes projects, tasks, claims, sources, tools, workflows
Git Brain	Tracks versions, snapshots, references, history, recovery
Agent Brain	Inspects, validates, indexes, cleans, summarizes, automates

This is stronger than a normal spreadsheet because it creates traceable state.

A normal row says:

“This task exists.”

A Mise Grid OS row says:

“This task exists, belongs to this project, came from this source, was last verified on this date, has this confidence level, was changed in this snapshot, and can be retrieved by AI with citation.”

CLAUDE.md

# Mise Grid OS Agent Instructions
This repository is an agent-native knowledge/workflow grid.
## Operating Rules
1. Treat rows as atomic records.
2. Never invent facts not present in Sources or Claims.
3. Every factual output must reference a Source ID when possible.
4. Preserve IDs, timestamps, confidence levels, and verification status.
5. Prefer small composable changes over broad rewrites.
6. Before editing schemas, update docs/schema.md.
7. Before changing workflows, update docs/operating-rules.md.
8. Run validation before committing.
## Agent Roles
- Inspector Agent: reads objects and records.
- Hasher Agent: creates stable object IDs.
- Indexer Agent: builds retrieval indexes.
- Verifier Agent: checks claims and sources.
- Snapshotter Agent: creates versioned snapshots.
- Cleaner Agent: archives stale or duplicate records.
## Safety
Do not remove source records unless they are archived first.
Do not mark claims verified without evidence.
Do not expose secrets, API keys, or private credentials.

New scripts to implement

scripts/hash-records.ts

Purpose: create stable IDs for rows.

import { createHash } from "node:crypto";
export function hashRecord(record: unknown): string {
  const canonical = JSON.stringify(record, Object.keys(record as object).sort());
  return createHash("sha256").update(canonical).digest("hex");
}

scripts/audit-claims.ts

Purpose: catch unsupported facts.

type Claim = {
  claim_id: string;
  claim: string;
  source_id?: string;
  confidence?: "high" | "medium" | "low" | "unknown";
  status?: "draft" | "verified" | "deprecated" | "archived";
};
export function auditClaim(claim: Claim): string[] {
  const issues: string[] = [];
  if (!claim.source_id) {
    issues.push(`Claim ${claim.claim_id} has no source_id.`);
  }
  if (claim.status === "verified" && !claim.source_id) {
    issues.push(`Claim ${claim.claim_id} cannot be verified without a source.`);
  }
  if (!claim.confidence) {
    issues.push(`Claim ${claim.claim_id} is missing confidence.`);
  }
  return issues;
}

scripts/validate-grid.ts

Purpose: enforce “everything in its place.”

type GridRecord = {
  id?: string;
  type?: string;
  status?: string;
  created_date?: string;
  canonical_summary?: string;
};
export function validateGridRecord(record: GridRecord): string[] {
  const errors: string[] = [];
  if (!record.id) errors.push("Missing id.");
  if (!record.type) errors.push("Missing type.");
  if (!record.status) errors.push("Missing status.");
  if (!record.created_date) errors.push("Missing created_date.");
  if (!record.canonical_summary) errors.push("Missing canonical_summary.");
  return errors;
}
