# Security Policy

Mise PR is designed to run locally inside GitHub Actions by default.

## Default data behavior

- No hosted backend is required.
- No LLM is required.
- No source code is sent to a third-party service by default.
- The action reads local git diff metadata and the GitHub Actions event payload.

## Reporting vulnerabilities

Open a private security advisory on GitHub or contact the maintainer through the repository owner profile.

Please include:

- affected version
- reproduction steps
- expected impact
- suggested fix if available
