This package establishes the foundation canon for MiseOS, GridOps, Chef Brigade 300, Mise Orchestra and the Registry.

## Canon status

- Official individual trading-card files with metadata are marked `canonical`.
- Strong title/catalog matches are marked `canonical-candidate`.
- Alias or role mappings are marked `provisional`.
- Generation One pages remain `unassigned` until owner approval.

This conservative approach prevents visual guesses from becoming production canon.
