# MiseOS Brand Architecture v2

## Positioning hierarchy

1. **MiseOS — Operating System and company**
   - Autonomous Development Platform
   - Agent Orchestration OS
   - Developer Operating System

2. **Brigade — Agent workforce product**
   - The autonomous workforce powering MiseOS.
   - Launch roster: 75 specialized agents across seven departments.

3. **Mascots — Brand layer**
   - Kurogami is the lead mascot and face of the platform.
   - Mascots support product comprehension, onboarding, events, and storytelling.

## Canonical message

> MiseOS coordinates AI agents, repositories, tools, workflows, infrastructure, and approvals into a single operational system.

## Product modules

- **Core** — identity, state, permissions, and execution control
- **Brigade** — specialized autonomous agents
- **Kitchen** — workspace and preparation layer
- **Orchestra** — workflow and multi-agent coordination
- **Vault** — secrets, approvals, evidence, and protected assets
- **Observatory** — telemetry, audit trails, reliability, and governance

## Collectible boundary

DevNFTs launch only after the platform. They represent participation, provenance, contribution, and access. They are not the operating system and are not required to use MiseOS.

The existing 112-character metadata collection remains a separate collectible/archive supply. The current commercial launch story uses a curated 75-agent Brigade roster. Registry manifests remain product infrastructure, never character cards.
