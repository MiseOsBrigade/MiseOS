# MiseOS Brand & Marketing Strategy

## Positioning

MiseOS is the kitchen operating system for autonomous development. Everything in its place before it ships.

## Correct Count Language

```text
112 character cards + 23 registry manifests = 135 MiseOS ecosystem items
```

Do not say `135 characters`. The registry manifests are product/package infrastructure.

## Core Audience

- Indie builders who need repo-safe automation.
- DevOps teams that need safer AI workflows.
- Open-source maintainers who need triage, releases, docs, and policy checks.
- Teams experimenting with MCP, GitHub Apps, and agentic CI/CD.

## Product Story

Every software team is a kitchen. Commits are ingredients. Pull requests are tickets. Releases are service. MiseOS gives every agent a station, every workflow a recipe, and every release an evidence trail.

## Content Pillars

1. Repo-safe AI agents.
2. GitHub automation and Marketplace tools.
3. DevOps kitchen mythology.
4. Character card reveals.
5. Open-core SaaS monetization.

## Weekly Cadence

- Monday: agent spotlight.
- Tuesday: repo-safe DevOps tip.
- Wednesday: build log.
- Thursday: card reveal.
- Friday: GitHub Action / MCP demo.
- Saturday: community poll.
- Sunday: weekly changelog.

## Monetization Ladder

```text
Community  → free docs, starter CLI, card gallery
Pro        → hosted repo manager, workflow linter, release reports
Team       → GitHub App, MCP connectors, policy packs, audit logs
Enterprise → self-hosted runtime, SSO, compliance, private deployment
```

## Launch Message

MiseOS turns autonomous development into coordinated service: 112 character agents, 23 registry manifests, and one repo-safe operating system for teams that ship with evidence.
