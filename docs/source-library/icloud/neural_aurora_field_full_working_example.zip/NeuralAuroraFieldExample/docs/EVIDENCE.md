# Evidence Notes

## Verified pieces

- Cødeart / CodeArt App Store listing says it is powered by p5.js and supports mathematical animation, particle systems, abstract visualizations, templates, tutorials, performance monitoring, save/share, and smooth mobile animation.
- p5.js documents `blendMode(ADD)` as additive blending where source and canvas color values are added.
- Apple Core ML is the official framework for integrating machine learning models into apps, with on-device prediction/training/fine-tuning support.
- Apple WKWebView is the native way to embed web content in an app UI.
- Apple WKScriptMessageHandler is the official JavaScript-to-native bridge mechanism for receiving messages from a web view.
- Apple Speech framework supports recognizing spoken words in live or recorded audio.
- Apple Keychain Services are for encrypted storage of small secrets.

## What is not verified

I did not find public evidence for a real official `developer.lumerie.com` SDK with iOS/Core ML integration. Treat "Lumerie SDK" as unknown until you have official documentation, headers, or an authenticated vendor portal.
